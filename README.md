# Learning Hub

Production-oriented study platform with a Spring Boot API, FastAPI AI service, React web application, PostgreSQL, Keycloak, and LiteLLM.

The approved product and engineering specifications are in [`docs/`](docs/README.md).

## Repository

```text
apps/api          Spring Boot public API and persistence owner
apps/ai-service   Internal AI content-generation service
apps/web          React web application
platform          Local platform and identity configuration
docs              Product and engineering design pack
```

Implementation is in progress. Never commit a real `.env` file or credentials.
